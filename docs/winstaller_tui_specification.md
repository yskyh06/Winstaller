# Winstaller TUI 화면 구성 및 인터랙션 상세 명세서

본 문서는 무인 Windows 자동 배포 도구인 **Winstaller**의 TUI(Terminal User Interface) 흐름, 화면 레이아웃, 대화형 옵션 및 보안 정책을 정의합니다.

---

## 1. 기본 원칙 및 보안 가이드라인
1. **제품명**: `Winstaller` (기존 Litewin 명칭 통합 변경)
2. **무의존성 경량 설계**: X11, Wayland, Qt, GTK 등의 무거운 의존성을 일절 배제하고, C++20 표준 I/O 및 ANSI VT100 이스케이프 시퀀스 기반으로 구동하여 추가 바이너리 용량 0MB 유지.
3. **OEM 라이선스 키 보안 정책**:
   - 메인보드 BIOS ROM(`/sys/firmware/acpi/tables/MSDM`)의 디지털 라이선스는 Home/Pro 에디션 자동 판별용으로만 메모리에서 사용.
   - 외부 서버 전송 일절 없음 (순수 로컬 동작).
   - 화면 및 로그에는 25자리 원본 키 노출을 금지하고 `OEM License: Windows 11 Pro (감지됨)` 형태로 마스킹 처리.

---

## 2. 표준 화면 흐름 (Linear Setup Flow)

전체 설치 흐름은 사용자 실수를 방지하고 편의성을 극대화하기 위해 다음과 같은 단방향 절차로 고정됩니다.

```text
[계약 동의] ➔ [Wi-Fi/네트워크] ➔ [디스크 선택] ➔ [Windows 버전/에디션 선택] ➔ [다운로드 및 배포 (실시간 계정설정)] ➔ [10초 카운트다운 재부팅]
```

- **아키텍처 자동 판별**: `x86_64` 또는 `aarch64(ARM64)`는 프로그램이 CPU/커널 환경을 감지하여 자동 결정(사용자에게 불필요한 질문 생략).
- **디스크 선택 필수화**: 아무리 권장 설치라도 데이터 보호를 위해 디스크 선택은 사용자가 반드시 직접 확인하고 지정.

## 3. 화면별 와이어프레임 및 동작 시나리오

### [화면 1] 면책 조항 및 라이선스 계약 동의 (EULA)
부팅 직후 가장 먼저 진입하는 필수 동의 화면입니다. 거부 시 안전하게 셸로 종료됩니다.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│  Winstaller - Automated Windows Deployment Tool                              │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  [ 면책 조항 및 이용 동의 (Disclaimer & License Agreement) ]                 │
│                                                                              │
│  1. 본 프로그램(Winstaller)은 사용자의 편의를 위한 자동화 도구입니다.         │
│  2. 디스크 파티션 생성, 포맷, 데이터 삭제 과정에서 발생하는 모든 데이터 손실,│
│     하드웨어 손상 및 라이선스 관련 법적 책임은 전적으로 사용자 본인에게       │
│     있으며, 개발자는 어떠한 법적·기술적 책임도 지지 않습니다.                 │
│  3. 설치를 진행하기 전 중요한 데이터는 반드시 사전 백업하시기 바랍니다.     │
│                                                                              │
│  위 내용을 충분히 이해하였으며, 이에 동의하십니까?                            │
│                                                                              │
│             [  동의함 (Agree & Enter)  ]        [  종료 (Exit)  ]             │
└──────────────────────────────────────────────────────────────────────────────┘
```

### [화면 2] 네트워크 환경 확인 및 Wi-Fi 설정
유선 이더넷(DHCP)이 이미 연결된 경우 이 화면은 자동으로 건너뜁니다. 유선 인터넷이 없을 때만 무선 네트워크를 검색하여 표시합니다.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│  Winstaller - Network Setup                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│  [!] 유선 네트워크가 연결되어 있지 않습니다. Wi-Fi에 연결해 주세요.          │
│                                                                              │
│  [ 검색된 무선 네트워크 목록 (Wi-Fi Networks) ]                              │
│   (*) MyHome_5G          [WPA2-PSK]  신호강도: 95%                          │
│   ( ) Office_Guest       [WPA2-PSK]  신호강도: 70%                          │
│   ( ) Free_Public_WiFi   [Open]      신호강도: 45%                          │
│                                                                              │
│  비밀번호 (Passphrase): [ ****************                   ]               │
│                                                                              │
│             [  연결 (Connect)  ]        [  새로고침 (Rescan)  ]               │
└──────────────────────────────────────────────────────────────────────────────┘
```

### [화면 3] 대상 디스크 선택 (Target Disk Selection)
데이터 유실 사고를 방지하기 위해, 모든 사용자는 설치할 대상 디스크를 직접 눈으로 확인하고 선택해야 합니다.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│  Winstaller - Target Disk Selection                                          │
├──────────────────────────────────────────────────────────────────────────────┤
│  Windows를 설치할 대상 디스크를 선택하세요:                                  │
│  ⚠️ 주의: 선택한 디스크의 모든 기존 파티션과 데이터가 영구 삭제됩니다.       │
│                                                                              │
│   (*) /dev/nvme0n1  [Samsung 980 PRO 1TB]       (권장 - 초고속 NVMe SSD)    │
│   ( ) /dev/sda      [Crucial MX500 500GB]       (SATA SSD)                  │
│                                                                              │
│  [선택된 디스크 정보]                                                        │
│  - 용량: 1,000.2 GB | 인터페이스: NVMe | 섹터 크기: 512 바이트               │
│  - 파티션 분할 예정: P1(WinRE 800M), P2(ESP 1G), P3(MSR 16M), P4(OS), P5(Temp)│
│                                                                              │
│             [  선택 및 다음 단계 (Enter)  ]        [  뒤로 (Back)  ]         │
└──────────────────────────────────────────────────────────────────────────────┘
```

### [화면 4] Windows 버전 및 에디션 선택
아키텍처는 프로그램이 시스템 하드웨어(`x86_64` 등)를 감지하여 자동 확정하며, Windows 11 기본값 및 감지된 OEM 라이선스 에디션을 추천합니다.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│  Winstaller - Windows Edition Selection                                      │
├──────────────────────────────────────────────────────────────────────────────┤
│  감지된 시스템 아키텍처: x86_64 (64-bit UEFI)                                │
│  감지된 메인보드 라이선스: Windows 11 Pro (자동 매칭됨)                      │
│                                                                              │
│  [1] 버전 선택 (Version)                                                     │
│      (*) Windows 11 (24H2 / 26H2 최신 빌드 - 기본값)                         │
│      ( ) Windows 10 (22H2 레거시 빌드)                                       │
│                                                                              │
│  [2] 에디션 선택 (Edition)                                                   │
│      (*) Windows 11 Pro  [OEM 권장]                                          │
│      ( ) Windows 11 Home                                                     │
│                                                                              │
│  [3] 표시 언어 (Language): [ 한국어 (ko-KR)                       ▼ ]        │
│                                                                              │
│             [  설치 시작 (Enter)  ]                [  뒤로 (Back)  ]         │
└──────────────────────────────────────────────────────────────────────────────┘
```

### [화면 5] 다운로드/배포 진행 + 실시간 사용자 환경 설정
ESD 다운로드 및 WIM 압축 해제가 진행되는 대기 시간(약 5~10분) 동안 하단 폼에서 사용자 계정 및 PC 이름을 직접 설정할 수 있습니다.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│  Winstaller - Deploying Windows 11 Pro (x86_64)                              │
├──────────────────────────────────────────────────────────────────────────────┤
│ [진행 상황]                                                                  │
│   작업 단계: [4/7] ESD 이미지 다운로드 중... (18.5 MB/s | 잔여: 02:15)        │
│   다운로드: [======================>                       ] 48% (2.1 / 4.4GB)│
│   전체 진행률: [=============>                                ] 32%          │
├──────────────────────────────────────────────────────────────────────────────┤
│ [선택 사항] 작업이 진행되는 동안 사용자 환경을 설정할 수 있습니다.            │
│  (미입력 시 기본값으로 자동 설정됩니다)                                      │
│                                                                              │
│   1. 사용자 이름 (Username)   : [ Alice                      ]               │
│   2. 로그인 암호 (Password)   : [ ********                   ]               │
│   3. 컴퓨터 이름 (PC Name)    : [ ALICE-LAPTOP               ]               │
│                                                                              │
│  [ Tab: 항목 이동 ]   [ Enter: 설정 저장 완료 ]   [ 방향키: 값 수정 ]         │
└──────────────────────────────────────────────────────────────────────────────┘
```

### [화면 6] 배포 완료 및 자동 재부팅 카운트다운 (10초 대기)
배포 작업이 완료되었을 때 사용자가 자리를 비웠거나 추가 설정을 진행하지 않았을 경우를 대비한 안전 장치입니다.

```text
┌──────────────────────────────────────────────────────────────┐
│                 🎉 모든 설치 준비가 완료되었습니다!          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  10초 후 기본 설정값으로 자동 저장되고 시스템이 재부팅됩니다.│
│                                                              │
│  카운트다운: [ 8초 남음... ]                                 │
│                                                              │
│  설정을 계속 수정하시려면 【아무 키나 누르세요】             │
│                                                              │
│            [  지금 바로 재부팅 (Enter)  ]                    │
└──────────────────────────────────────────────────────────────┘
```
- **키 입력 시**: 카운트다운 타이머가 즉시 정지되고 사용자 설정 폼([화면 5])으로 복귀.
- **10초 타임아웃 만료 시**: 기본값(`User`, 무암호, 랜덤 PC 이름)으로 무인 스크립트를 최종 저장하고 Windows Setup(WinPE)으로 자동 재부팅.
