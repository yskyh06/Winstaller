# Winstaller TUI 단계 간소화 및 면책 조항 개편 세부 구현 방안

## 1. 개편 목적 및 방향
- **단계 최소화**: 기존 5단계(EULA ➔ Wi-Fi ➔ 디스크 ➔ 포맷 모달 ➔ 에디션)를 **단 2단계**로 축소.
- **안전성 확보**: 데이터 파괴 위험이 있는 '대상 디스크 선택'은 단독 분리하여 오입력 참사 방지.
- **법적 면책 보장**: 디스크 선택 화면에 데이터 파괴 경고 및 이용 약관 동의 간주 문구를 명시하고, `E` 키로 언제든 전문 열람 가능하도록 Clickwrap 표준 구현.
- **실전 정품인증 최적화**: Windows 11 에디션 기본값을 대기업/OEM 노트북 표준인 **Home (Index 4)**으로 변경 (BIOS MSDM에 Pro 키 감지 시에만 Pro 자동 승격).
- **네트워크 0초 패스**: 유선 랜 또는 인터넷 연결 시 네트워크 설정 화면 자동 건너뛰기.

---

## 2. 화면 흐름 정의 (2-Screen Workflow)

```text
[부팅 (RAM)] 
    ↓ (유선 랜 감지 시 0초 자동 패스 / 오프라인일 때만 Wi-Fi 화면 표시)
[화면 1: 대상 디스크 선택 & EULA 간주 & 포맷 확정]
    ↓ (Enter: 디스크 확정 / E: EULA 전문 모달)
[화면 2: 올인원 추천 설정 대시보드] (Windows 11 Home 기본값, 한국어, P5 캐시 자동)
    ↓ (Enter: 배포 즉시 시작 / B: 디스크 화면 복귀)
[실시간 설치 파이프라인 + 30ms 계정 설정]
```

## 3. 구현 세부 사항

### 3.1. 화면 1: 디스크 선택 화면 개편 (`prompt_disk_selection`)
- 별도 EULA 화면(`prompt_eula`)을 첫 단계에서 제거.
- 디스크 선택 화면 내에:
  1. `⚠️ 주의: 선택한 디스크의 모든 데이터가 영구 삭제됩니다.` 경고 표시.
  2. `※ 계속 진행(Enter) 시 소프트웨어 무보증 및 법적 면책 약관에 동의한 것으로 간주됩니다. [전문 보기: E]` 문구 추가.
  3. `E` / `e` 키 입력 시 `show_eula_modal()` 팝업을 띄워 전체 법적 고지 전문을 표시하고 `Enter`/`Esc`로 닫기.
  4. 버튼: `[ 동의 및 디스크 선택 (Enter) ]`, `[ 약관 전문 (E) ]`, `[ 종료 및 재부팅 (Esc) ]`.

### 3.2. 화면 2: 에디션 & 추천 설정 대시보드 개편 (`prompt_edition_selection`)
- 기본 에디션: **Windows 11 Home (Index 4)**.
- 메인보드 ACPI MSDM 테이블에서 "Pro" 라이선스가 명시적으로 감지될 때만 Windows 11 Pro (Index 6) 자동 선택.
- 비활성 캐시 행 스킵 및 한국어 기본값 유지.

### 3.3. `main.cpp` 상태 머신 간소화
- 유선 랜/인터넷 활성 시 `SetupStep::Wifi` 자동 패스.
- EULA 독립 단계를 제거하고 `SetupStep::Disk` ➔ `SetupStep::Edition` ➔ `SetupStep::Done`의 2단계 루프로 축소.

---

## 4. 작업 Goal
- **Goal 1**: `WinstallerTui`에 EULA 상세 모달(`show_eula_modal`) 및 디스크 선택 화면 내 약관 간주·경고 통합.
- **Goal 2**: 에디션 기본값을 Windows 11 Home으로 변경하고 MSDM Pro 감지 시에만 Pro 추천 적용.
- **Goal 3**: `main.cpp`에서 유선 랜 자동 통과 및 2단계 상태 머신 축소 반영.
- **Goal 4**: 단위 테스트 갱신 및 전체 87개 테스트 통과 검증, 최종 Docker ISO 빌드 및 검증.
