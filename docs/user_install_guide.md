# Winstaller 왕초보 설치 가이드

> **스마트폰 QR 코드로 들어오신 분들을 환영합니다!**
> 컴퓨터를 잘 몰라도 이 가이드를 보면서 천천히 따라 하시면 누구나 10분 만에 새 윈도우 설치를 끝낼 수 있습니다.

---

## 1. 시작하기 전 준비물 확인

설치를 시작하기 전 두 가지만 확인해 주세요.

1. **Winstaller 부팅 USB**: 이미 컴퓨터에 꽂혀 있거나 가지고 계신 전용 USB입니다.
2. **인터넷 연결**:
   - **유선 인터넷(랜선)**: 본체 뒤에 랜선이 꽂혀 있다면 가장 좋습니다. 별도 설정 없이 바로 진행됩니다.
   - **무선 인터넷(Wi-Fi)**: 랜선이 없다면 설치 시작 시 화면에 나오는 와이파이를 선택하고 비밀번호를 입력하면 됩니다.
   - **스마트폰 USB 테더링 (비상시 꿀팁)**: 랜선도 없고 Wi-Fi도 안 될 때는 스마트폰과 PC를 케이블로 연결한 뒤 폰 설정에서 **USB 테더링**을 켜면 유선 인터넷처럼 바로 인식됩니다.

> [!CAUTION]
> **중요한 파일은 미리 옮겨두셨나요?**
> 윈도우를 새로 깔면 기존 컴퓨터에 있던 사진, 동영상, 문서 등 파일이 지워집니다. 소중한 파일은 외장하드, 다른 USB, 혹은 클라우드에 먼저 옮겨두고 진행해 주세요!

---

## 2. 컴퓨터를 켜고 USB로 부팅하는 방법

컴퓨터가 꺼진 상태에서 Winstaller USB를 꽂고 전원을 켭니다. 
컴퓨터가 켜지자마자 화면이 나오기 전에 **아래 표에 맞는 단축키를 1초에 2번씩 톡-톡-톡 연타**합니다.

| 컴퓨터 / 메인보드 제조사 | 부팅 메뉴 단축키 (연타할 키) |
| :--- | :---: |
| **삼성 (Samsung)** | **`F10`** 또는 **`ESC`** |
| **LG (그램 등)** | **`F10`** |
| **ASUS (에이수스)** | **`F8`** 또는 **`ESC`** |
| **MSI** | **`F11`** |
| **GIGABYTE (기가바이트)** | **`F12`** |
| **ASRock (애즈락)** | **`F11`** |
| **레노버 (Lenovo)** | **`F12`** |
| **HP (휴렛팩커드)** | **`F9`** |
| **한성컴퓨터 / 주연테크** | **`F7`** 또는 **`F11`** |
| **DELL (델)** | **`F12`** |

> **부팅 장치 선택 창이 뜨면?**
> 화살표 키(`↑`, `↓`)로 내 USB 이름(보통 `UEFI: ...` 로 시작하는 항목)을 고르고 **`Enter(엔터)`**를 누르면 Winstaller가 시작됩니다.

---

## 3. 화면별 따라 하기 (딱 3번만 선택하면 끝!)

Winstaller 화면이 나타나면 마우스 대신 **키보드의 화살표 키(`↑`, `↓`)**와 **`Enter(엔터)` 키**로 조작합니다.

### [1단계] 이용 약관 동의 화면
- 검은색 화면에 영문과 한글로 면책 동의 창이 뜹니다.
- 당황하지 마시고 키보드의 **`Enter(엔터)` 키**를 가볍게 한 번 눌러주시면 다음으로 넘어갑니다.

### [2단계] 인터넷 연결 (랜선이 없을 때만 뜸)
- 랜선이 꽂혀 있다면 이 화면은 **자동으로 건너뛰어집니다.**
- 만약 Wi-Fi 화면이 떴다면:
  1. 화살표 키로 우리 집 와이파이 이름을 찾고 **`Enter`**를 누릅니다.
  2. 와이파이 비밀번호를 타이핑하고 **`Enter`**를 누르면 연결 완료!
- **랜선도 없고 와이파이도 안 될 때 꿀팁**:
  - 스마트폰 충전 케이블로 스마트폰과 본체를 연결하고 스마트폰 설정에서 **`USB 테더링`**을 켜세요.
  - Winstaller가 유선 인터넷으로 바로 인식하여 5초 후 자동으로 다음 단계로 넘어갑니다!

### [3단계] 윈도우를 설치할 디스크 선택 (★가장 중요!)
- 화면에 내 컴퓨터에 장착된 드라이브 목록이 표시됩니다.
- **어떤 걸 골라야 할까요?**
  - 모델명 옆에 **`nvme`** 또는 **`SSD`**라고 적혀 있고, 용량이 큰 주 드라이브(예: `500 GB`, `1000 GB` 등)를 고르시면 됩니다.
  - 보통 **맨 첫 번째 항목(`> (*) ...`)**에 가장 빠른 SSD가 기본으로 선택되어 있으므로, 웬만하면 그대로 **`Enter(엔터)`**를 누르시면 됩니다.

### [4단계] 윈도우 버전 및 언어 확인
- 화면에 **`Windows 11 Home`** 또는 **`Windows 11 Pro`**가 자동으로 추천되어 있습니다.
  - 메인보드에 정품 키가 있는 컴퓨터는 내 정품 키에 맞는 에디션이 알아서 골라져 있습니다.
- 언어도 **`Korean (ko-KR)`**로 기본 설정되어 있습니다.
- 바꿀 필요가 없다면 그대로 맨 아래 **`[ Start Installation (Enter) ]`**에서 **`Enter(엔터)`**를 누르면 설치가 시작됩니다!

## 4. 기다리는 동안 (5분 ~ 10분)

이제 사용자가 할 일은 끝났습니다. 컴퓨터가 알아서 마이크로소프트 정품 서버에서 최신 윈도우를 내려받아 설치합니다.

### 꿀팁: 지금 USB를 뽑으셔도 됩니다!
Winstaller는 부팅되자마자 프로그램 전체가 컴퓨터 메모리(RAM)로 복사되었습니다.
따라서 **설치가 진행되는 도중에 USB를 쏙 뽑아서 다른 컴퓨터에 쓰시거나 치워두셔도 아무 문제 없이 100% 정상 설치**됩니다.

### 화면에 보이는 진행률 바 설명
- **작업 단계 [1/7 ~ 7/7]**: 현재 어떤 작업을 하는지 보여줍니다.
- **다운로드 진행률**: 인터넷에서 윈도우 순정 파일을 받는 속도와 남은 시간입니다.
- **사용자 이름/비밀번호 (선택 사항)**:
  - 기다리는 동안 화면 아래에 영문 사용자 이름을 입력할 수 있습니다.
  - **아무것도 안 건드려도 됩니다!** 아무것도 입력하지 않으면 자동으로 가장 편한 기본 사용자 이름(`User`)으로 설정되어 로그인 화면이 스킵됩니다.

## 5. 설치 완료 후 첫 부팅 & 바탕화면 진입

설치가 끝나면 화면에 **"10초 후 자동으로 재부팅됩니다"**라는 문구가 뜨고 컴퓨터가 스스로 꺼졌다 켜집니다.

1. **설치 USB가 아직 꽂혀 있다면 지금 바로 뽑아주세요!**
   - USB가 꽂혀 있으면 다시 설치 프로그램으로 부팅될 수 있습니다.
2. **윈도우 로고와 함께 "잠시만 기다려 주세요" 화면이 지나갑니다.**
   - 복잡한 계정 로그인이나 업데이트 대기 화면 없이 **곧바로 깨끗한 바탕화면이 열립니다.**
3. **C 드라이브 용량은 알아서 늘어납니다.**
   - 첫 부팅 시 설치에 썼던 임시 공간을 컴퓨터가 스스로 지우고 C 드라이브 용량을 최대로 늘려주니 용량 걱정은 하지 않으셔도 됩니다.

## 6. 설치 후 이것만 해주세요! (마무리 팁)

바탕화면에 들어오셨다면 딱 두 가지만 챙겨주세요.

1. **인터넷 연결하기**:
   - 화면 오른쪽 아래 작업표시줄의 와이파이/네트워크 아이콘을 눌러 와이파이를 연결해 주세요.
2. **윈도우 업데이트 한 번 돌리기**:
   - `시작` 버튼 $\rightarrow$ `설정(톱니바퀴)` $\rightarrow$ `Windows 업데이트` $\rightarrow$ **`업데이트 확인`** 버튼을 누릅니다.
   - 그래픽 카드, 사운드 등 컴퓨터에 필요한 필수 드라이버를 마이크로소프트가 알아서 최신으로 다 잡아줍니다.
3. **정품 인증 확인**:
   - 메인보드에 정품 키가 내장된 노트북이나 브랜드 PC는 인터넷이 연결되는 즉시 자동으로 정품 인증이 완료됩니다.

## 7. 자주 묻는 질문 (FAQ)

**Q. 도중에 멈춘 것 같아요. 컴퓨터를 강제로 꺼도 되나요?**
> 파일 크기가 크기 때문에 1~2분 정도 진행률 숫자가 멈춘 것처럼 보일 수 있습니다. 하드디스크에 열심히 기록 중인 상태이므로 전원 버튼을 누르지 마시고 3분 정도만 더 기다려 주세요.

**Q. 설치하다가 빨간 글씨로 오류가 났어요!**
> 오류 화면에 나타난 **오류 해결 전용 QR 코드**를 스마트폰으로 비춰보세요. 어떤 문제인지와 해결 방법이 바로 스마트폰 화면에 안내됩니다.
